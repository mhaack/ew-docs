# Experience Workspace diagrams

This repository contains architecture and workflow diagrams for the Experience Workspace ecosystem.

## Diagrams

- `da-architecture.html` / `da-architecture.json` — original DA platform architecture
- `da-architecture2.html` / `da-architecture2.json` — presentation-friendly DA architecture
- `experience-workspace-ecosystem.html` / `experience-workspace-ecosystem.json` — external ecosystem / dependency view
- `da-ux-workflow.html` / `da-ux-workflow.json` — UX workflow diagram

## Editing

The `.json` files are the Archify sources.
The `.html` files are generated artifacts.

After updating a JSON source, regenerate the matching HTML with Archify deliver.
